# 📈 FinPulse

FinPulse is an Indian Stock Market Dashboard developed using Python, Streamlit, FastAPI, SQLite, Plotly, and Yahoo Finance API.

## Features

- Live Stock Data
- Historical Price Analysis
- Candlestick Charts
- Moving Average Analysis
- Company Filtering
- Sorting by Price, Market Cap and PE Ratio
- KPI Cards
- Download Historical Data as CSV
- Refresh Live Market Data

## Technologies Used

- Python
- Streamlit
- FastAPI
- SQLite
- Plotly
- Yahoo Finance API

## Dataset

Live data is fetched from Yahoo Finance using the yfinance library.

## How to Run

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
